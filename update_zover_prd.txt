# PRD & ERD: Fitur "Running Text" (Dynamic Branding Carousel) - ZoVer

## 1. Tujuan & Ringkasan Fitur (Overview)
Membangun fitur overlay baru bernama **Running Text** untuk sistem **ZoVer**. 
Catatan Penting: Meskipun bernama "Running Text", perilaku visualnya **BUKAN** teks berjalan horizontal (marquee), melainkan **Vertical Flip Slide Carousel** (pergantian slide berurutan di tengah layar dengan animasi gepeng vertikal / 3D X-Axis Flip `rotateX(90deg) scaleY(0.1)`), persis seperti referensi video branding stream.

Fitur ini terdiri dari:
1. **Dashboard Admin (CRUD Slide & Pengaturan Global):** Mengelola daftar slide (teks baris 1, teks baris 2, opsional logo di atas teks, durasi tampil, urutan slide).
2. **OBS Overlay View (`/overlay/running-text`):** Halaman transparan khusus OBS Browser Source yang merender rotasi slide secara real-time, bebas memory leak, dan hemat CPU/GPU.

3. Spesifikasi Fungsional (Functional Requirements)
A. Modul Dashboard (Control Panel ZoVer)
Manajemen Slide Dinamis:

User dapat menambah slide baru (+ Tambah Slide), mengubah isi, mengaktifkan/menonaktifkan slide tertentu, mengubah urutan (sort_order), dan menghapus slide.

Setiap slide memiliki toggle Tampilkan Logo (show_logo). Jika aktif, user bisa memilih/upload gambar logo atau memakai URL gambar yang sudah ada.

Input teks dibagi menjadi Baris 1 (wajib) dan Baris 2 (opsional) agar pemenggalan kalimat rapi seperti referensi video.

Input Durasi Tampil (ms/detik) per slide (default 3000 ms).

Real-Time Sync ke Overlay:

Saat user menekan tombol Simpan / Terapkan, backend menyimpan perubahan dan langsung memancarkan event (running_text_updated) melalui WebSocket / Server-Sent Events (SSE) / BroadcastChannel ke halaman overlay OBS tanpa perlu refresh manual di OBS.

B. Modul OBS Overlay (/overlay/running-text)
Layout & Tipografi:

Background halaman wajib transparent (rgba(0,0,0,0)).

Posisi konten berada di tengah (center horizontal & vertical), dengan susunan vertikal (flex-direction: column): Logo di bagian atas, diikuti Teks Baris 1 dan Teks Baris 2 di bawahnya.

Font menggunakan Poppins (Bold Italic - 700i/800i) warna putih (#FFFFFF) dengan text-shadow: 0px 3px 6px rgba(0, 0, 0, 0.45) agar kontras di atas layar game.

Logika Transisi & Animasi (Wajib Sesuai Referensi):

Menggunakan CSS 3D Transform pada sumbu X:

State Keluar (.flip-out): transform: rotateX(90deg) scaleY(0.1); opacity: 0;

State Masuk (.flip-in): transform: rotateX(0deg) scaleY(1); opacity: 1;

Smart Logo Transition:

Jika slide saat ini dan slide berikutnya sama-sama menampilkan logo yang sama (contoh: Slide 1 ke Slide 2), maka elemen Logo TIDAK ikut melakukan flip (tetap diam/stay di atas), hanya teks di bawahnya saja yang melakukan animasi flip-out dan flip-in.

Jika slide berikutnya tidak memakai logo (show_logo: false seperti pada Slide 3) atau mengganti gambar logo, maka elemen Logo ikut melakukan animasi .flip-out lalu disembunyikan (display: none).

4. Non-Functional Requirements & Guardrails (Standar Audit Qoder)
Keamanan XSS (Cross-Site Scripting):

Dilarang keras menggunakan innerHTML saat merender text_line_1 dan text_line_2 di sisi overlay. Wajib menggunakan element.textContent.

Validasi ekstensi dan sanitasi URL pada atribut src untuk logo_url.

Zero Memory Leak & Optimasi CPU Rendah:

Dilarang membuat ulang elemen DOM pada setiap pergantian slide. Gunakan kembali (reuse) 1 struktur DOM statis (#logoWrapper, #line1, #line2).

Pastikan semua setTimeout (slideTimer dan transitionTimer) selalu dibersihkan dengan clearTimeout() sebelum membuat timer baru atau saat menerima update data baru dari WebSocket/SSE.

Hanya gunakan properti komposit GPU (transform dan opacity) untuk animasi agar beban CPU di OBS mendekati 0%.
